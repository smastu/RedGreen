# RedGreen

窓の赤・緑ボタンの動きを変える、メニューバー常駐の小さなアプリ（Swift）。

- **緑ボタン**：全画面ではなく、画面いっぱい（Dock とメニューバーを除く）に広げる。もう一度押すと元の大きさに戻る。⌥ を押しながらなら macOS 標準の動き
  - 押したまま左／右にドラッグ → 左半分／右半分（もう一度同じ操作で元に戻る）、上にドラッグ → 画面いっぱい
  - 長押し → 配置メニュー（左半分・右半分・画面いっぱい・元に戻す・macOS 標準の全画面）
- **黄色ボタン**：クリックはふつうに Dock にしまう。長押し、またはマウスを乗せて止めるとメニュー（この窓／このアプリの窓をすべて／すべてのアプリの窓を Dock にしまう、しまった窓を戻す）。⌥ を押しながらなら macOS 標準の動き
- **赤ボタン**：すぐ離せば今までどおり（閉じて、最後の窓ならアプリも終了）。長押し、またはマウスを乗せて止めると「この窓だけ閉じる（最後の窓でも終了しない）／アプリを終了」を選べる。⌥ を押しながらなら macOS 標準の動き
  - マウスを乗せたときのメニューはメニューバーから切れる。マウスの位置を 0.15 秒ごとに見て、0.5 秒止まったときだけボタンかを調べる（軽い）
- **最後の窓を閉じたら終了**（Swift Quit と同じ）：赤ボタンでも ⌘W でも、アプリの普通の窓が 0 になったらアプリを終了する
- 終了させないアプリ：`~/Library/Application Support/RedGreen/exclude.txt`（アプリ名かバンドル ID。初期値は Finder・MSLite・LiteDeck・ResourceWatch）
- **使っていないアプリを自動で終了**：窓が 0 のまま 10 分、窓があっても 30 分、前面に出していないアプリを終了（時間はメニューで変更・オフ可）。
  Mac を使っている間（最後の操作から 2 分以内）だけ数えるので、離席中にまとめて終了することはない。保存の確認が出たら終了しない
- **Finder と横に並べる**（コピー・アップロード用）：メニューバーから「〇〇 と Finder を横に並べる」（前面のアプリが左、Finder が右）、
  「Finder を 2 つ横に並べる」。どちらも高さは画面いっぱい。Finder の窓が足りなければ自動で開く。緑ボタンの長押しメニューにも「Finder と横に並べる」
- **⌘Tab を窓ごとの切り替えに**（Windows の Alt+Tab 風）：アプリ単位ではなく窓 1 枚ずつ（最小化・非表示の窓、窓のないアプリも）。
  ⌘ を押したまま Tab／⇧Tab／矢印で選んで離すと切り替え、Esc で取り消し、クリックでも選べる。すぐ離せば直前の窓へ。
  一覧はアイコンと窓の題名だけ（画面収録の許可は不要）。標準の ⌘Tab は RedGreen の動作中だけ止め、終了時に戻す
- **Finder に編集できるアドレス欄**：前面の Finder の窓の下端に今のフォルダのフルパスを表示。クリックで全選択、
  パスを打って（~ も可）Return で移動、ファイルなら開く、Esc で取り消し。
  入力中は欄の上に候補を一覧表示（フォルダが先）。Tab で補完（1 件ならそれに、複数なら共通部分まで）、↑↓で選択、1 回目の Esc で一覧を閉じる。初回に「オートメーション」（Finder の操作）の許可が必要。
  Finder が前面のときだけ動く
- **Finder で ⌘X → ⌘V をファイルの移動に**（Command X の代わり）：⌘X で Finder の「コピー」を押して印を付け、次の ⌘V で「ここに項目を移動」を押す。
  間にほかのものをコピーしたら印は消え、ふつうのペーストになる。名前の変更中や検索欄など、文字を入力している最中はふつうの ⌘X
- **Finder で Windows のキー**：Enter で開く、Delete でゴミ箱（入れる前に「ゴミ箱に入れますか？」と確認。メニューで切れる。⌘⌫ は確認なし）、F2 で名前の変更。ファイルの一覧にキーボードが向いているときだけ（名前の変更中・検索欄・確認の画面はそのまま）
- **Dock のアイコンで最小化**（Windows のタスクバー風）：前面のアプリの Dock アイコンを押すと、そのアプリの窓を Dock にしまう。もう一度押せば戻る。⌥ を押しながらなら標準の動き
- **Home／End を行の先頭・末尾へ**：アプリではなく設定ファイル。リポジトリの `DefaultKeyBinding.dict` を `~/Library/KeyBindings/` に置く（Mac 標準の作りのアプリで有効。起動し直したアプリから効く）
- **すべての窓を Dock にしまう**：全アプリの窓をまとめて最小化（標準の ⌥⌘M は前面のアプリだけ）。「しまった窓を戻す」で元どおり
- **アプリをまとめて終了**：メニューバーから、対象外以外のアプリを全部、または 1 つずつ終了
- 自動終了・まとめて終了の対象外：`~/Library/Application Support/RedGreen/keep_running.txt`（初期値はターミナル類・SlackLite・MSLite・音楽・会議アプリ）と exclude.txt のアプリ
- メニューバーのアイコンから、それぞれのオン・オフ、除外リストの編集、ログイン時の起動（LaunchAgent `local.matsumoto.RedGreen`）

アクセシビリティの許可が必要（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。

## 言語（Language）
日本語・英語を内蔵。メニュー「言語（Language）」で切り替え（「自動」はシステムの優先言語に合わせる）。
ほかの言語は **言語パッチ**（JSON）で追加できる：

1. メニュー「言語」→「翻訳用のひな形を書き出す…」で `_template.json`（英語）ができる
2. 訳して `<言語コード>.json`（例 `fr.json`、`zh-Hans.json`）の名前で
   `~/Library/Application Support/RedGreen/lang/` に置く。`"_language"` に表示名を書く
3. メニューに出るので選ぶ（再起動不要）

- 足りないキーは英語で表示。`%@` は差し込み位置なので数を変えない
- 内蔵の日本語・英語も、`ja.json` / `en.json` を置けば一部だけ上書きできる
- リポジトリの `lang/` に置いたパッチはアプリに同梱される（例：`lang/zh-Hans.json` 简体中文）

## ビルド
`./build.sh` → `~/Applications/RedGreen.app`（main.swift・Switcher.swift・FinderBar.swift）。
自己署名の証明書「Shimpei Local Code Signing」があればそれで署名するので、作り直してもアクセシビリティの許可が消えない。

## 注意
- 赤ボタンのクリックと ⌘W を見張り、閉じたあと（0.7・2・5 秒後）にそのアプリの普通の窓が 0 なら終了。メニューの「ウインドウを閉じる」やスクリプトで閉じた場合は対象外（アクセシビリティの「窓が消えた」知らせはアプリによって届かないため、この方式にした）
- 記録：~/Library/Logs/RedGreen.log
